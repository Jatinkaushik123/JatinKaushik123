# Font Licenses and Attribution

This repository bundles and inlines base64-encoded WOFF2 font subsets inside the animated SVG profile assets for pixel-accurate cross-platform typography without making external HTTP requests.

## 1. Space Grotesk (Bold 700)
- **Author**: Florian Karsten
- **Source**: [https://github.com/floriankarsten/space-grotesk](https://github.com/floriankarsten/space-grotesk)
- **License**: SIL Open Font License, Version 1.1 ([licenses/SPACE_GROTESK_OFL.txt](./licenses/SPACE_GROTESK_OFL.txt))
- **Usage**: Primary oversized display headlines, titles, and section headers.

## 2. JetBrains Mono (SemiBold 600)
- **Author**: JetBrains / Philipp Nurullin
- **Source**: [https://github.com/JetBrains/JetBrainsMono](https://github.com/JetBrains/JetBrainsMono)

- **Usage**: Terminal prompts, mono subtitles, metadata pills, metrics, and technology chips.
